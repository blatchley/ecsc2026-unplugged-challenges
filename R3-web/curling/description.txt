Do you `wget` the pun?

Extract the handout with:
```sh
mkdir curling; tar xf curling_offline.tar.xz -C curling
```

The laptop doesn't have internet, docker or podman, so you can't build the handout locally, but we've added a sudoless docker runtime and added a prebuilt image that you should be able to run with `./run.sh`. 

If you want a shell in the container, you can run:
```sh
PATH="$PWD/runtime/bin:$PATH" UDOCKER_DIR="$PWD/.udocker" UDOCKER_TMP="$PWD/.udocker/tmp" python3 runtime/udocker-1.3.17/udocker/udocker --config=udocker.conf run challenge /bin/sh
```
